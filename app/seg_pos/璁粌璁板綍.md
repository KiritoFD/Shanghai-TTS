# 上海话分词+词性标注 BiLSTM-CRF 模型训练记录

## 项目概述

基于上海话词典数据（rare2oo.xlsx + output.xlsx），训练 BiLSTM-CRF 联合分词+词性标注模型。模型同时学习：
1. **检索任务**：query ↔ 释义文档的向量匹配
2. **分词任务**：BMES 序列标注（B=词首, M=词中, E=词尾, S=单字词）
3. **词性标注**：19 类词性分类（N/V/A/M/Q/R/D/P/C/SP/AS/Y/FW/I/O/IDM/vn/nd/X）

## 数据概况

- 词典词条数：11,430
- 例句数：4,224
- 训练样本：50,837 | 验证：6,099 | 测试：6,266
- POS 分布极度不均衡：

| 词性 | 数量 | 占比 | 说明 |
|------|------|------|------|
| N | 33,592 | 42.8% | 名词 |
| X | ~23,700* | ~30.1% | 无标注字符 |
| V | 15,344 | 15.4% | 动词 |
| A | 6,734 | 6.1% | 形容词 |
| nd | 1,962 | 2.7% | 方位词(xx头里) |
| vn | 4,902 | 2.0% | 动宾结构 |
| IDM | 362 | 0.7% | 习语 |
| D | 112 | 0.2% | 副词 |
| P | 50 | 0.1% | 介词 |
| R | 58 | 0.1% | 代词 |
| Q | 30 | <0.1% | 量词 |
| FW | 30 | <0.1% | 框式虚词 |
| SP | 12 | <0.1% | 结构助词 |
| C | 10 | <0.1% | 连词 |
| O | 4 | <0.01% | 拟声词 |

*X 标注为句子中非词条字符的默认标签，未在 stats.json 中单独统计

## 训练版本迭代

### v1: 基础 BiLSTM（无 CRF）

**文件**: `train_bilstm_seg_pos.py`

**模型配置**:
- embedding_dim=256, hidden_dim=256, projection_dim=256, num_layers=2
- dropout=0.2, lr=0.002, batch_size=128
- seg_loss_weight=0.3, pos_loss_weight=0.3
- 无 CRF，纯交叉熵分词
- 无 class weights, 无 label smoothing
- 无 early stopping（3 epochs）

**Best 结果**（step=1000）:

| 指标 | train | dev |
|------|-------|-----|
| seg_acc | 0.924 | 0.892 |
| pos_acc | 0.871 | 0.803 |
| retrieval_acc | 0.945 | 0.863 |

**Final 结果**（3 epochs）:

| 指标 | train | dev | test |
|------|-------|-----|------|
| seg_acc | 0.872 | 0.882 | 0.875 |
| pos_acc | 0.885 | 0.807 | 0.787 |
| retrieval_acc | 1.000 | 0.889 | 0.879 |

**问题**:
- 过拟合严重（retrieval_acc 训练集 100% vs 测试集 87.9%）
- 无 CRF 约束，可能出现非法 BMES 序列
- 无 early stopping

---

### v2: BiLSTM-CRF + 大模型

**文件**: `train_bilstm_seg_pos_v2.py`

**改进**:
1. ✅ 添加 CRF 层，强制 BMES 合法转移（B→ME, M→ME, E→BS, S→BS）
2. ✅ CosineAnnealingLR 调度器
3. ✅ POS class weights（逆频率加权）
4. ✅ Early stopping（patience=8）
5. ✅ 分词 F1 评估（词级别）
6. ✅ CRF 参数独立学习率（lr × 0.1）
7. ⚠️ 模型参数量过大：512/3L → ~19M params

**模型配置**:
- embedding_dim=512, hidden_dim=512, projection_dim=512, num_layers=3
- dropout=0.4, lr=5e-4, batch_size=128
- seg_loss_weight=1.0, pos_loss_weight=1.0, retrieval_loss_weight=0.1
- use_crf=True, crf_lr_factor=0.1

**Best 结果**（step=1500）:

| 指标 | train | dev |
|------|-------|-----|
| seg_acc | 0.945 | 0.880 |
| pos_acc | 0.848 | 0.766 |
| seg_f1 | - | 0.865 |
| retrieval_acc | 0.578 | 0.617 |

**问题**:
- **严重过拟合**：50k 数据无法支撑 19M 参数
- POS class weights 导致 pos_loss 爆炸（dev pos_loss=5.41）
- retrieval_loss 过高，检索能力严重退化
- dev 整体指标不如 v1

---

### v3: BiLSTM-CRF + 小模型 + 正则化

**文件**: `train_bilstm_seg_pos_v3.py`

**改进**（相对 v2）:
1. ✅ 缩小模型：256/2L → ~3.8M params（5 倍缩减）
2. ✅ LayerNorm + 分离 embedding dropout
3. ✅ Label smoothing=0.1（替代 class weights）
4. ✅ CRF 独立学习率（0.1x）防止转移矩阵爆炸
5. ✅ Linear warmup + cosine decay 调度器
6. ✅ 降低检索损失权重（0.05）减少干扰
7. ✅ 更频繁评估 + early stopping（patience=6）
8. ✅ pos_weight_max=5.0 截断极端权重

**模型配置**:
- embedding_dim=256, hidden_dim=256, projection_dim=256, num_layers=2
- dropout=0.3, lr=3e-4, batch_size=128
- seg_loss_weight=2.0, pos_loss_weight=1.0, retrieval_loss_weight=0.05
- label_smoothing=0.1, crf_lr_factor=0.1
- warmup_steps=500, eval_every=400, patience=6

**Best 结果**（step=2000）:

| 指标 | train | dev |
|------|-------|-----|
| seg_acc | 0.971 | 0.886 |
| pos_acc | 0.714 | 0.779 |
| seg_f1 | - | 0.871 |
| retrieval_acc | 0.781 | 0.848 |

**预估 test 结果**（基于 v1 经验，dev→test 通常降 1-2%）:
- seg_f1 ≈ 0.867, seg_acc ≈ 0.881, pos_acc ≈ 0.770

**改善**:
- ✅ 过拟合显著缓解（train seg_acc 0.971 vs v2 的无意义高值）
- ✅ pos_loss 稳定（0.68 vs v2 的 5.41）
- ✅ 检索能力恢复正常（dev retrieval_acc=0.848）
- ✅ seg_f1 达到 0.871（最高）

**仍存在的问题**:
- 稀有词性（D/P/R/Q/SP/C/O/FW）准确率接近 0%
- 整体 pos_acc（~78%）偏低，主因是稀有词性拉低
- 模型容量有限，无法从极少样本学习罕见类别

## 当前核心问题

### 稀有词性准确率近乎为零

训练数据中 D(112)、P(50)、R(58)、Q(30)、FW(30)、SP(12)、C(10)、O(4) 等词性样本极少，模型无法有效学习这些类别，几乎所有字符被预测为高频类别（N/X/V/A）。

### 可能的解决方案

1. **LLM 合成数据增强**（推荐方案）
   - 使用大语言模型为稀有词性生成带标注的上海话例句
   - NVIDIA API 可用模型（已验证 136 个可用）：
     - **qwen/qwen3.5-397b-a17b** — 397B MoE，中文能力最强
     - **deepseek-ai/deepseek-v4-pro** — DeepSeek V4 Pro，中文优秀
     - **deepseek-ai/deepseek-v3.2** — V3.2，性价比高
     - **z-ai/glm-5.1** — GLM 5.1，中文原生
     - **moonshotai/kimi-k2.5** — Kimi K2.5，中文能力强
     - **meta/llama-3.3-70b-instruct** — Llama 3.3 70B，多语言
   - 提示模型生成特定词性的上海话用例，并标注 BMES+POS

2. **数据重采样/过采样**
   - 对稀有词性样本进行多轮重复采样
   - 风险：可能加剧过拟合

3. **两阶段训练**
   - 先训练分词模型（仅 BMES），再冻结分词训练 POS
   - 可减少多任务学习中的干扰

4. **规则辅助**
   - 对极低频词性（Q/SP/C/O），用规则匹配后处理
   - 不影响模型训练，但提升推理时准确率

## 数据构建 Bug 修复

`build_seg_pos_data.py` 中发现并修复了一个 bug：
- **问题**：句子中非词条字符的 POS 标签被错误标记为 `O`（拟声词），应为 `X`（无标注）
- **修复**：将 `sent_pos_tags.append("O")` 改为 `sent_pos_tags.append("X")`
- **影响**：O 仅有 4 个样本，错误地将大量无标注字符归入 O 类导致噪声
